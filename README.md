# SkillSwap-Peer-Learning-Redefined
SkillSwap is a web-based platform where students exchange skills through peer learning. Create a profile, get smart matches, schedule sessions, and collaborate via chat. Ideal for first-years and campus clubs. Built with HTML frontend, Firebase backend/database, and hosted on Firebase/Vercel. 
Whether you're great at coding, design, public speaking, or video editing — and want to learn something new — SkillSwap matches you with fellow students who complement your learning goals.

#🚀 **Features**
🧠 Create a profile with skills you can teach and skills you want to learn

🔄 Smart matching system to pair students for learning sessions

📅 Schedule 1-on-1 or group sessions

💬 Connect through chat and collaborate

🎯 Lightweight, beginner-friendly, and perfect for campus use

#🛠️ **Tech Stack**
Frontend: HTML / React.js / Streamlit

Backend: Firebase / Supabase

Database: Firebase Firestore / Realtime DB

Hosting: Firebase Hosting / Vercel

#🌱 **Ideal For**
First-year students, campus clubs, and hackathons looking to promote informal, skill-based collaboration in a smart and simple way.
